# Agentic Incident Memory

Agentic incident troubleshooting application using CockroachDB as persistent memory and AWS services for execution and AI inference.

## Planned stack

- CockroachDB Cloud
- CockroachDB Managed MCP Server
- CockroachDB Distributed Vector Indexing
- Amazon Bedrock
- AWS Lambda
- Amazon API Gateway
- Amazon S3
- AWS SAM
